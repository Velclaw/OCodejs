03 / API reference

API cần kiểm chứng được.

Mỗi module nên đi kèm chữ ký, ví dụ chạy được và kiểm thử. Trạng thái bên dưới là checklist tài liệu, không khẳng định tính năng đã phát hành.

ModuleTài liệu cần cóKiểm thử
stringInput/output, Unicode, escapingEdge cases
objectDeep paths, merge semanticsNested values
asyncRetry, timeout, cancellationResolve/reject/race
url / httpParsing, status, request errorsMalformed URL / timeout
validationConstraints and error formatBoundary values
04 / Form components

Biểu mẫu cùng hệ thống giao diện.

Mẫu form tham chiếu để thống nhất cách trình bày input, select, textarea và nút hành động với thiết kế OCode.js. Đây là demo giao diện, không gửi dữ liệu đi đâu.

Demo chỉ hiển thị bản xem trước trong trình duyệt; không gửi hoặc lưu thông tin.
